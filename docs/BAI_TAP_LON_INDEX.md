## 📊 THÔNG TIN DỰ ÁN

### Tổng quan
- **Tên dự án**: SumUp - AI Text Summarization App
- **Thời gian**: 12 tuần (3 tháng)
- **Team size**: 5 thành viên
- **Phương pháp**: Agile/Scrum
- **Version**: 1.0.3
- **Status**: ✅ Production Ready

### Vai trò Thành viên

| # | Vai trò | Tên | Trách nhiệm |
|---|---------|-----|-------------|
| 1 | **PM** (Project Manager) | Alice | Quản lý dự án, điều phối team, stakeholder communication |
| 2 | **BA** (Business Analyst) | Bob | Phân tích yêu cầu, viết use cases, documentation |

| 4 | **Backend Developer** | David | Domain layer, use cases, API integration, database |
| 5 | **Frontend Developer** | Eve | Compose UI, navigation, ViewModels |
| 6 | **Tester** | Frank | Test plan, automation, quality assurance |

### Tech Stack
- **Language**: Kotlin 2.0.21
- **UI**: Jetpack Compose + Material 3
- **Architecture**: Clean Architecture + MVVM
- **DI**: Hilt 2.51
- **Database**: Room 2.6.1
- **Network**: Retrofit 2.11.0 + OkHttp 4.12.0
- **AI**: Google Gemini 1.5 Flash API
- **Document**: PDFBox, Mammoth
- **OCR**: ML Kit Text Recognition
- **Min SDK**: 24 (Android 7.0)
- **Target SDK**: 35 (Android 15)
