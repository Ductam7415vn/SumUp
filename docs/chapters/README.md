  - Text Input, PDF Upload, OCR, History & Settings
- 2.3. Phác thảo Giao diện (Wireframing)
  - Wireframes cho 7 màn hình chính

**[04_CHAPTER_3.md](./04_CHAPTER_3.md)** - Chương 3: Thiết kế Visual và Hệ thống Thiết kế

  - Mobile, Tablet, Desktop layouts
- 3.4. Tạo Mẫu thử Tương tác (Interactive Prototype)
  - Animations, micro-interactions, accessibility

**[05_CHAPTER_4.md](./05_CHAPTER_4.md)** - Chương 4: Kiểm thử, Đánh giá và Tinh chỉnh
- 4.1. Lập kế hoạch Kiểm thử (Test Plan)
  - 12 participants, 8 tasks, metrics
- 4.2. Tiến hành Kiểm thử (Usability Testing)
  - Quy trình, công cụ, thu thập dữ liệu
- 4.3. Tổng hợp Kết quả và Phân tích
  - Task Success Rate: 90.6% → 100%
  - SUS Score: 78.5 → 87.2 (Grade A)
  - 10 issues discovered (5 major, 5 minor)
- 4.4. Đề xuất và Thực hiện Tinh chỉnh
  - Design solutions, before/after comparisons
  - Re-testing validation
