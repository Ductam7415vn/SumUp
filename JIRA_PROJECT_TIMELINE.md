### **SUMUP-BUG-001: Hilt Kapt Build Failure**
**Type:** Bug
**Priority:** Blocker
**Story Points:** 1
**Sprint:** 1
**Status:** ✅ Fixed
**Assigned:** Lead Developer

**Error:**
```
error: [Dagger/MissingBinding] Cannot provide Context without @ApplicationContext qualifier
```

**Root Cause:**
Missing `@ApplicationContext` annotation in providers.

**Fix:**
```kotlin
@Provides
@Singleton
fun provideContext(@ApplicationContext context: Context): Context = context
```

**Lesson Learned:**
Always use qualifiers for Context injection in Hilt.

```kotlin
@Singleton
class SummarizeTextUseCase @Inject constructor(
    private val repository: SummaryRepository
) {
    operator fun invoke(text: String, persona: SummaryPersona): Flow<Result<Summary>> = flow {
        emit(Result.Loading)

        try {
            val summary = repository.summarizeText(text, persona)
            repository.saveSummaryToLocal(summary)
            emit(Result.Success(summary))
        } catch (e: Exception) {
            emit(Result.Error(e.toAppError()))
        }
    }
}
```

```kotlin
override suspend fun extractTextFromPdf(pdfDocument: PdfDocument): PdfExtractionResult {
    return withContext(Dispatchers.IO) {
        val uri = Uri.parse(pdfDocument.uri)
        val inputStream = context.contentResolver.openInputStream(uri)
```

### **SUMUP-BUG-051: DNS Resolution Failure for Gemini API**
**Type:** Bug
**Priority:** Blocker
**Story Points:** 3
**Sprint:** 6
**Status:** ✅ Fixed
**Date:** 2025-10-07

**Error:**
```
UnknownHostException: Unable to resolve host "generativelanguage.googleapis.com"
```

**Root Cause:**
Android 9+ Private DNS conflicting with OkHttp DNS resolver.

**Fix:**
```kotlin
val builder = OkHttpClient.Builder()
    .dns(object : okhttp3.Dns {
        override fun lookup(hostname: String): List<InetAddress> {
            return try {
                okhttp3.Dns.SYSTEM.lookup(hostname)
            } catch (e: UnknownHostException) {
                // Fallback DNS resolution
                InetAddress.getAllByName(hostname).toList()
            }
        }
    })
```
